# animated-lesson · 动画讲解课

把技术概念、机制、数据讲成**会动的讲解**：可播、可拖、可截图断言、可导出视频。

Web 原生（`canvas2d` + WGSL 风格的 `three` 可选），**零 npm 依赖** —— 只要 Node 22 和系统 Chrome。

**先看这两个**：

- 🎬 [`out/intro-why-stroke-by-stroke.mp4`](out/intro-why-stroke-by-stroke.mp4) —— **元课件**：用这个模式介绍这个模式（8 幕 / 226 秒 / 1920×1080）
- 🎬 [`out/why-stroke-by-stroke.mp4`](out/why-stroke-by-stroke.mp4) —— **按笔画示例**：de Casteljau / A* / SDF 五个 case（5 幕 / 98 秒）
- 🎬 [`out/fourier.mp4`](out/fourier.mp4) —— **傅立叶变换**：主张→机制→量级→边界→推论（5 幕 / 160 秒）
- 🌐 [`intro.html`](intro.html) —— 一页看完背景 / 优势 / 场景 / 人群（`./serve.sh` 后打开）

## 两个核心想法

### 1. 确定性时间轴：`render(t)` 是纯函数

场景文件里**禁止** `Date.now()` / `Math.random()` / `performance.now()`，`draw(ctx, t, el, api)` 的 `t` 是唯一的输入。

这一条约束换来四件事：

| 换来 | 因为 |
|---|---|
| **可拖拽** | 任意时刻都能直接渲染出来，不需要从头播一遍 |
| **可断言** | 同一个 `t` 渲染两次必须逐字节相同 → 确定性可以被**门禁**检查 |
| **可出片** | 逐帧 seek 导出，视频没有闪烁、没有掉帧 |
| **可复现** | 同一份课件在任何机器上出来是同一帧 |

代价是拒绝有状态动画（`Date.now()` 驱动的粒子、物理引擎的累积状态、幕间转场）。
**这个代价值得付** —— 上面四件事是教学课件比"炫技动画"更需要的。

### 2. 教学不是"把字放大"，是**论证链完整**

每一幕都该有五环，其中三环**已经被工具量化**：

| 环 | 判据 | 谁来管 |
|---|---|---|
| **主张** | 一句可反驳的话，不是话题 | 作者 |
| **机制** | 画面必须真的在编码信息 | **G11**：扰动声明的 `data`，画面必须跟着变 |
| **量级** | 有数字 **且** 数字有参照 | `lint-scenes.mjs` 体检表 |
| **边界** | 说清楚什么时候不成立 | `lint-scenes.mjs` 体检表 |
| **推论** | 观众能自己往下算一步 | 预测题 + 溯源 |

> 只有支持证据的讲解是**宣传**，不是教学。

## 快速开始

```bash
./serve.sh                        # 预览 → http://127.0.0.1:8099/

# 有材料的话从这里开始：素材 → 能跑、能过门禁的骨架（并列出待补的缺项）
node scripts/from-md.mjs docs/你的文档.md --out=templates/scenes.mine.js

node scripts/lint-scenes.mjs      # 静态校验 + 内容深度体检（毫秒级）
node scripts/verify.mjs           # 19 项浏览器断言 + 出片链路
./scripts/check-all.sh            # 交付前一键：lint + 链接 + 7 份课件全量门禁 + 负向测试
node scripts/gate-selftest.mjs    # 负向测试：证明门禁真的会失败（造坏课件 → 要求报红）

# 一键出片：帧直接管道进 ffmpeg，不落盘
node scripts/verify.mjs --deck='templates/deck.html?scenes=./scenes.mine.js' \
     --mp4=out/mine.mp4 --fps=24 --size=1920x1080
```

## 22 项门禁：凭什么说"讲清楚了"

一半是**技术门禁**（防止坏了），一半是**教学门禁**（防止空转）。

| | 断言 | 抓什么 |
|---|---|---|
| **G0** | CSS 里的每个 `#id` 必须在 DOM 里存在 | 选择器写错 → 元素丢掉定位、退化成 grid 行、把舞台挤变形 |
| **G0b** | 主题落到 app 根，舞台/控制条/字幕条的 `--bg` 一致 | 半截主题（浅色舞台配深色控制条） |
| **G1** | 能起来、校验器无错、console 无 error | 语法错、初始化顺序错 |
| **G2** | 所有元素都在视口内 | 元素跑出画面 |
| **G2b** | 盒内文字未被裁切 | 看不到图的作者最容易漏的 |
| **G2d** | 三类遮挡实测为 0：覆盖层压内容 · 画布内标注互压 · 标注被裁 | 「看起来有点遮挡」的全部三类 |
| **G3** | 每幕早晚截图必须不同 | **静态 PPT 冒充动画** |
| **G4** | 同一 `t` 双渲染逐字节相同 | `Date.now` / `Math.random` 污染 |
| **G5** | 每条旁白在其时刻字幕已显示且文字一致 | 旁白与字幕错位 |
| **G5b** | 字幕恒为单行 | 字幕换行 → 安全带高度随文案变 |
| **G6** | 预测题：点选标对错、答错显示解释、答案被记录 | 题目点了没反应 |
| **G7** | 每个画布的平均 alpha > 0 | `draw()` 没画东西 / 画到画布外 |
| **G8** | `?three=off` 后 3D 元素切 2D 降级且**仍在动** | CDN 挂了就开天窗 |
| **G9** | 每 0.5s 窗口内首次出现的信息单元 ≤ 3 | 一页 8 个元素同时弹出（认知过载） |
| **G9b** | 同时生长的笔画 ≤ 4 | 一次画太多笔 |
| **G10** | 标记单调的画布：可见笔画长度只增不减 | 画好的东西被擦掉、闪烁 |
| **G11** | 扰动 `data`，**画面必须跟着变** | **装饰性画面**：看着像回事但读不出任何一个值 |
| **FRAMES / MP4** | 一键出片，帧直接管道进 ffmpeg | 视频链路是否真的通 |
| **G13** | `image` 必须真的解码成功且带 `credit` | 缺图开天窗、图片没标出处 |
| **G12** | 出片后量字幕带亮度：旁白时刻必须明显亮于无旁白时刻 | 「声称字幕已烘焙、其实成片里没有」 |

**G0 / G2d / G11 / G12 / G14 都是被真实事故逼出来的**，不是先想出来的门禁：
三个 CSS id 写错导致舞台被裁 17px；画布内标注互相压；元课件 7 块画布全是硬编码坐标；
以及我自己声称过"字幕已烘焙"而实际没有。

## 从 OpenMAIC 抄了什么，以及**故意没抄**什么

抄了：两阶段生成（outline → scenes）、Action Engine 抽象、声明式 DSL、离线导出。

故意没抄：Next.js + Postgres 多平台、多 agent 生成、富文本拖拽编辑器、全部 21 个 action。

理由写在 [`references/design-notes.md`](references/design-notes.md)：**瓶颈是"判断该讲什么"，不是生成吞吐**；
而且课件是**代码**才可能可 diff、可 lint、可被门禁管。

## 边界与诚实说明

- 门禁需要 Chrome；没有 Chrome 的 CI 只能跑 `lint-scenes.mjs`
- 导出的视频**没有音轨**（字幕是唯一的讲解通道，所以才要 G12 保证它真的在画面里）
- 幕间是硬切，**故意不做转场**（会掩盖内容，也让截图对比失效）
- `out/` 里的视频是确定性导出的，但 GitHub 的 diff 看不了 mp4 —— 改课件请重新生成再比
