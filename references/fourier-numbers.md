# 傅立叶课件的数字从哪来

`templates/scenes.fourier.js` 里的每一个数字都由 `scripts/fourier-numbers.mjs` 算出。
**这份文档存在的理由**：课件里凡是写"量级"的地方，都必须能被独立复现 ——
否则"量级"这一环就是编的，观众也没有任何办法核对。

## 复现

```bash
node scripts/fourier-numbers.mjs
```

## 方波：f_N(x) = (4/π) Σ_{k 奇 ≤ N} sin(kx)/k

真值取 N=20001。RMS 误差排除跳变点 ±0.05 rad 的邻域（跳变处的"真值"本身无定义），
按跳变幅度 2 归一化：

| N | RMS 误差 |
|---|---|
| 1 | 20.310% |
| 3 | 13.597% |
| 5 | 10.285% |
| 9 | 6.761% |
| 21 | 2.951% |
| 49 | 1.655% |
| 99 | 0.803% |
| 499 | 0.165% |

**参照**：项数 ×99（1 → 99），误差 ÷25（20.31% → 0.80%）。
系数按 1/k 衰减，误差大致按 1/√N 降 —— 所以想把误差再降 10 倍，项数要多约 100 倍。

## 吉布斯超调

跳变附近峰值 − 平台值 1，以跳变幅度 2 归一化：

| N | 峰值 | 超调 / 跳变幅度 |
|---|---|---|
| 9 | 1.182328 | 9.116% |
| 99 | 1.179013 | 8.951% |
| 999 | 1.178980 | **8.949%** |
| 20001 | 1.178980 | **8.949%** |

**边界**：N 从 9 加到 999（×111），超调只从 9.116% 降到 8.949%，然后停住。
**加项数只让尖峰变窄，不让它变矮。**

## 频谱泄漏

sin(3t) 在长度 T 的窗口上投影，`|(1/T) ∫ f(t)·e^{-iωt} dt|`：

| 窗口长度 | \|ω=3\|（匹配） | \|ω=4.5\|（邻频） |
|---|---|---|
| 1 个周期 | 0.5000 | **0.2546** |
| 1.25 个周期 | 0.5040 | 0.2361 |
| 1.5 个周期 | 0.5000 | 0.1200 |
| 2 个周期 | 0.5000 | **0.0000** |

**边界**：傅立叶的"正交"不是无条件的 —— 它依赖窗口长度是信号周期的整数倍。
窗口只有一个周期时，邻频被看见的强度是匹配值的 51%。这是 DFT 频谱泄漏的根源。

## 时频测不准

高斯窗 exp(−t²/2σ²)，数值求方差：

| σ_t | σ_ω | σ_t · σ_ω |
|---|---|---|
| 0.25 | 4.0000 | **1.0000** |
| 0.5 | 2.0000 | **1.0000** |
| 1 | 1.0000 | **1.0000** |
| 2 | 0.5000 | **1.0000** |

**推论**：乘积恒等于 1，四组 σ 全部精确相等。想让时间看清楚 σ_t 减半，
频率就一定糊一倍（σ_ω 翻倍）。**没有免费的取舍点，只有换位置。**

工程上的具体数字（44.1 kHz 采样）：

| 窗长 | 时间分辨率 | 频率分辨率 |
|---|---|---|
| 1024 点 | 23.2 ms | 43.07 Hz |
| 256 点 | 5.8 ms | 172.3 Hz |

时间准 4 倍，频率就糊 4 倍。

| 幕 | 用到的数字 |
